# 📡 Kwork Radar

Мониторит публичную ленту заказов Kwork и **мгновенно пингует тебя в Telegram**
по релевантным заказам (Android/Kotlin, боты, парсеры, автоматизация) — с уже
готовым **черновиком отклика** под конкретный заказ.

> ⚠️ **Радар НЕ отправляет отклики сам.** Он только показывает тебе горячие
> заказы и даёт заготовку. Отклик ты правишь под задачу и отправляешь **руками**
> на сайте Kwork. Это осознанно: авто-отклики нарушают правила Kwork (бан
> аккаунта) и заказчики их сразу палят. Радар даёт главное преимущество —
> **скорость**: ты узнаёшь о заказе за минуты и отвечаешь первым, по-человечески.

---

## Что тебе это даёт

- Не сидишь весь день на бирже — заказы сами прилетают в ЛС бота.
- Видишь свежак с «Предложений: 0–2» → отвечаешь первым, пока конкуренты спят.
- Каждый пинг = карточка: бюджет, срок, кол-во откликов, оценка «горячести»,
  прямая ссылка + готовый черновик (нажал на текст — скопировался).
- Кнопки «✅ Откликнулся» / «🚫 Скип» — чтобы не терять, где уже был.

## Установка (один раз)

На этом ПК **зависимости уже установлены** (папка `venv`), так что можно сразу
переходить к настройке. Если переносишь проект на другой ПК — запусти
`install.bat` (нужен Python 3.11+ с python.org, галка «Add to PATH»).

### 1. Создай Telegram-бота
1. Напиши [@BotFather](https://t.me/BotFather) → команда `/newbot`.
2. Придумай имя и username → получишь **токен** вида `123456789:AA...`.

### 2. Узнай свой chat_id
Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой **id** (число).

### 3. Заполни конфиг
1. Скопируй файл `.env.example` → `.env` (просто копия рядом, имя ровно `.env`).
2. Открой `.env` блокнотом и впиши:
   - `BOT_TOKEN=` — токен от BotFather
   - `CHAT_ID=` — твой id от userinfobot
   - `PORTFOLIO_URL=` — ссылка на портфолио или твой ТГ (пойдёт в черновик)
3. **Важно:** после создания бота один раз напиши ему в ЛС `/start` или
   любое сообщение — иначе Telegram не даст боту написать тебе первым.

## Запуск

### Проверить, что всё работает (без Telegram)
Двойной клик по **`check.bat`** — Радар сходит на Kwork и напечатает найденные
заказы прямо в консоль. Так удобно крутить фильтры, не спамя себе в ТГ.

### Боевой режим
Двойной клик по **`run.bat`** — Радар запускается, пишет тебе «📡 Radar
запущен» и дальше каждые 3–7 минут проверяет ленту и шлёт новые заказы.
Чтобы остановить — закрой окно консоли.

## Настройка под себя (файл `.env`)

| Параметр | Что делает |
|---|---|
| `MIN_BUDGET` | Минимальный бюджет заказа, ₽ (дешевле — игнор). По умолчанию 1500. |
| `MAX_NOTIFY` | Сколько заказов слать за один цикл (чтобы не заваливало). |
| `POLL_MIN_SECONDS` / `POLL_MAX_SECONDS` | Интервал опроса (случайный в этом диапазоне). |
| `TG_PROXY` | Прокси для Telegram, если CityLink режет `api.telegram.org` (см. ниже). |
| `HEADFUL` | `1` — показать окно браузера (для отладки), `0` — прятать в фон. |

**Ключевые слова и стоп-слова** живут в `radar/config.py`:
- `DEFAULT_KEYWORDS` — по чему искать в ленте Kwork.
- `DEFAULT_STRONG_INCLUDE` — обязательный «сигнал разработки» (иначе заказ
  отбрасывается как не твоя тема).
- `DEFAULT_EXCLUDE` — стоп-слова (SMM, накрутки, монтаж и т.п.).

## Если что-то не так

- **Telegram не отвечает / ошибка отправки.** Скорее всего CityLink режет
  `api.telegram.org`. Впиши в `.env` рабочий прокси в `TG_PROXY`
  (например `socks5://127.0.0.1:PORT` от твоего dedproxy) и перезапусти.
- **«bot can't initiate conversation».** Напиши боту `/start` в ЛС — Telegram
  не даёт ботам писать первыми, пока ты сам не начал диалог.
- **Браузер не стартует.** Радар использует твой системный Google Chrome. Если
  Chrome обновится/переедет — обычно всё равно находится сам; в крайнем случае
  установи Visual C++ Redistributable (x64) с сайта Microsoft.
- **Kwork начал показывать капчу.** Увеличь интервал (`POLL_MIN_SECONDS` /
  `POLL_MAX_SECONDS`), чтобы ходить на сайт реже и мягче.

## Как устроено (кратко)

```
Fetcher (Chrome/Playwright)  →  тянет ленту по ключевикам
   ↓
Matcher                      →  фильтр (границы слов) + оценка «горячести»
   ↓
State (SQLite)               →  чтобы не пинговать дважды
   ↓
Drafts (шаблоны)             →  черновик отклика под тип заказа
   ↓
Notifier (Telegram-бот)      →  карточка тебе в ЛС + кнопки
   ↓
ТЫ                           →  правишь черновик и отвечаешь РУКАМИ на Kwork
```
